# Changelog

## 1.0.2 — 2026-09-25

Wiadomości odświeżają się automatycznie co 5 minut i po powrocie do okna aplikacji. Pobieranie omija nieaktualne odpowiedzi pośrednich pamięci podręcznych. Nadal można odświeżać ręcznie.

## 1.0.1 — 2026-09-25
Nazwa wyświetlana pakietu MSIX została dopasowana do potwierdzonej rezerwacji `AI-News`. Walidacja sprawdza teraz zarówno `Package/Properties/DisplayName`, jak i nazwę aplikacji oraz wersję manifestu.

## 1.0.0 — 2026-09-13
Pierwsza wersja Windows: API wiadomości, wyszukiwanie, kategorie, sortowanie, ulubione offline, schowek, drukowanie oraz motywy jasny, ciemny i systemowy.
